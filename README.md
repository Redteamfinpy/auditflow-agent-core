# AuditFlow: The AI-Optimized Document Audit Agent (Built with Windsurf)

AuditFlow was built to be read, maintained, and extended by modern AI development tools. By enforcing rigid, documented structures, we provide perfect IDE auto-complete and enable tools like Windsurf to generate audit code instantly. It's the fastest document review agent you'll ever maintain.

## Quickstart

```bash
pip install auditflow-agent-core
auditflow audit-file --file-path document.pdf --opt-in true
```

## Why AuditFlow?

- **AI-First DX**: Designed for AI tools to understand and extend effortlessly.
- **Auditability**: Every action is traceable and transparent.
- **Anonymous Improvement**: Opt-in telemetry helps improve the agent without compromising privacy.
